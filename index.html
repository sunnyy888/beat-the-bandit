What Thompson believes

Each curve is Beta(1 + wins, 1 + losses) for one machine. Each pull, Thompson draws one random number from every curve and pulls the machine with the highest draw. Wide curves = still uncertain, so they sometimes win the draw (exploration). Narrow, high curves win most draws (exploitation).

How to play

Click a machine (or press 1, 2, 3) to pull it. Each pull pays 1 coin with that machine's hidden probability. Every time you pull, both algorithms make one pull too, on the same three machines with their own luck.

Regret = coins you'd expect from always pulling the best machine, minus the coins your choices are expected to earn: Σ (best rate − rate of machine pulled). Lower is better, and unlike coins it doesn't depend on luck.

Easy: rates far apart. Hard: within a few points of each other, so you need many pulls to tell them apart.
